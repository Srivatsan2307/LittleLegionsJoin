Privacy Policy

Little Legions · Silver Spectre Software · 23 November 2026

This policy describes what the Little Legions game stores about you. The game is published by Silver Spectre Software. Questions go to support@silverspectresoftware.com.

What we store

  • A device id, so the roster on this phone or browser opens again next time.
  • The commander name you choose, your player tag, and whether your profile is private.
  • Game progress: decks, collection, gold, gems, cups, account level, tasks, battle records, and Order membership.
  • An email address only if you choose Save progress or switch to a saved roster. We send a one-time code to that address and do not use it for marketing.

What we do not do

The game does not show ads. Gold and gems are in-game currency. The game does not sell them for real money, and it does not sell your information.

Who can see it

Other players can see your name, tag, and the army from a battle. If you turn on Private profile, your profile stays hidden when someone opens it from a battle. Order members can see the name you use in that Order. Our game server stores the roster so it can run battles, the shop, and Orders.

How long it stays

The roster stays while the account exists. You can ask us to delete the email saved on it, or the account, by writing to the address above from that email.

Children

Little Legions is not directed at children under 13. We do not ask for a date of birth. See the Parents page.
